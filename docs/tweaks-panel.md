# Layout panel

The floating Layout panel provides quick, persistent workspace presentation controls. It can be hidden entirely from Settings.

## Layout controls

Tweaks currently supports:

- compact or regular interface density;
- bottom, left, or right placement for the workspaces dock;
- workspaces drawer height when the dock is at the bottom;
- workspaces sidebar width when the dock is on either side.

## Quick actions

Tweaks includes workspace drawer and Settings actions. The command palette remains available through its normal keyboard shortcut and is not duplicated in Tweaks.

## Onboarding

First-run onboarding introduces Tweaks after the Git sidebar step. It explains layout density and workspaces dock placement/sizing.
